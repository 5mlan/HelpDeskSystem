# Changelog

All notable changes to this project are documented here.

## [1.1.0] - 2026-08-30

### Added

- Automatic SLA target based on ticket priority.
- Overdue ticket indicator on the dashboard and ticket lists.
- Complete activity timeline for ticket creation, assignment, comments, status changes, and closure.
- CSV export for administrators and technicians.
- GitHub Actions build workflow and Dependabot configuration.
- Docker and Docker Compose support.
- Issue, pull request, security, and contribution templates.
- Full Arabic project and source-code guide.

## [1.0.0] - 2026-08-30

### Added

- ASP.NET Core MVC application with SQLite.
- ASP.NET Identity authentication and role-based authorization.
- Ticket creation, search, filtering, assignment, comments, status updates, and closure.
- Dashboard statistics and user-role management.
- Responsive Arabic interface.
